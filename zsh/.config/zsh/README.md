# ZSH Configuration

This is a pretty neat, sub 50ms init, ZSH config, with builtin gitprompt, syntax highlighting,
autosuggestions, fzf history backsearch and more

As it is deployed with [nix](https://github.com/arminveres/nix-conf/blob/main/modules/home/modules/zsh.nix), to use this standalone, one needs to setup some files.
To make it easy and simple, run the [./ssetup.zsh] script.
